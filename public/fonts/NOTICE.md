# Bundled fonts

The web UI is fully self-contained and does not contact any external host. The following fonts are bundled
in this directory (WOFF2, Latin subset):

| Files | Font | Copyright | License text |
|---|---|---|---|
| `inter-latin-400.woff2`, `inter-latin-500.woff2`, `inter-latin-600.woff2` | [Inter](https://github.com/rsms/inter) | The Inter Project Authors | [LICENSE-Inter.txt](LICENSE-Inter.txt) (SIL Open Font License 1.1) |
| `material-icons-outlined.woff2` | Material Icons (Outlined) | Google Inc. | [LICENSE-MaterialIcons.txt](LICENSE-MaterialIcons.txt) (SIL Open Font License 1.1, as shipped with the npm package) |

The font files and the license texts were taken unmodified from the npm packages `@fontsource/inter` and
`@fontsource/material-icons-outlined`. The license texts are kept verbatim; please do not edit them.
